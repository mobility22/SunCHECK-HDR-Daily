# SunCHECK-HDR-Daily

Tampermonkey userscript for SunCHECK HDR Bravos daily QC (v1.24)

The script only starts its automation when the visible page shows "Bravos" (for example the top bar `Daily | <date> | HDR_Bravos`). It waits for the SunCHECK SPA to load, re-evaluates when you navigate in the app, and does nothing if that text never appears.

Install or update from: https://raw.githubusercontent.com/mobility22/SunCHECK-HDR-Daily/refs/heads/main/suncheck-hdr-daily.user.js
